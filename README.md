# Проект информационной системы университета на NodeJs

## Требования

### Для запуска проекта вам потребуется: 
#### -Node.js версии от 20.13.1
#### -Yarn версии от 1.22.22 

#### Yarn можно установить через
    npm install -g yarn
  ## Установка и запуск
  
  ### 1. Скачайте или клонируйте репозиторий:
  
  ### 2. Перейдите в директорию проекта через терминал:
    cd <путь к проекту>
  
  ### 3. Установите зависимости:
    yarn install
  
  ### 4. Запустите контейнер MongoDB
    docker run -d -p 27018:27017 --name mongo mongo:latest
  
  ### 5. Запустите контейнер RabbitMQ
    docker run -d --hostname my-rabbit --name some-rabbit -p 5672:5672 -p 15672:15672 rabbitmq:3-management

  ### 6. Запустите проект: 
    yarn run dev
